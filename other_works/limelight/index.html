Limelight

Redesign

LimeLight is a cross-platform music player app designed to deliver an intuitive and visually engaging experience that balances aesthetics with flawless functionality. The project focused on creating a seamless user journey for browsing, discovering, and playing music with a modern dark-themed interface enhanced by dynamic visual elements. This interface was built for both mobile and web platforms, emphasizing consistency, accessibility, and high performance.

Challenges

The goal was to build a music player that stands out visually and functionally in a competitive market. Users needed to effortlessly navigate through their music library, discover new drops, and control playback without friction. The interface had to be visually immersive yet accessible, supporting both casual listeners and power users.

Research and Insights :

Through user research and competitive analysis, key insights included:

  • Users desire easy navigation between playlists, favorites, and new music.
  • Visual comfort is critical for long listening sessions, favoring dark themes that reduce eye strain.
  • Clear content hierarchy and strong branding enhance user trust and engagement.
  • Accessibility features and touch-friendly controls improve usability across devices.
  • Dynamic visuals and animations increase user delight.

Design Overview

  • A sleek black background paired with a vibrant green accent color forms the core brand identity.
  • The LimeLight logo reinforces a fresh, modern look.
  • Dark theme supports visibility of dynamic album art and UI elements.

Navigation and Layout

  • Bottom bar navigation organizes key sections: Home, Browse, Library, Connect.
  • Content is segmented into “Best of your collection,” “New drops,” and “Recommended for you” for easy discovery.
  • Album artwork is prominently displayed to create an immersive browsing experience.

Player Interface

  • Central playback controls feature large buttons for accessibility.
  • Dynamic visualizer arcs around album art add motion and engagement.
  • Essential features like shuffle, repeat, volume, favorites, and lyrics are seamlessly integrated.

Responsiveness

  • Design is optimized for mobile and web, ensuring consistent experience and rapid performance.
  • Grid layouts and scalable assets support different screen sizes.

Possible Outcomes

  • Enhanced user retention and session length attributed to intuitive navigation and immersive visuals.
  • Positive feedback on aesthetics, particularly the dark mode’s comfort and modern feel.
  • Improved accessibility with clear, touch-friendly controls.
  • Scalable design system facilitates future feature expansion.

Future Scopes

  • Implement gesture shortcuts for faster control.
  • Leverage AI for personalized playlist and music recommendations.
  • Integrate social features enabling playlist sharing and artist follow.
  • Expand visual animations and interactive backgrounds during music playback.
